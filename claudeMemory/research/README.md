# Research

Research notes and investigations for the SculptCore integration. One file per
topic (`<short-kebab-name>.md`).

Use this for focused deep-dives into the codebase (how a subsystem actually
behaves, spikes, prototype findings) that inform the design and plans but are
not themselves plans. Prefer concrete `file:line` evidence; note the date and
that line numbers drift.
